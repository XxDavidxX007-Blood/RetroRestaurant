# 🔔 NotifController — Marcar Notificaciones como Leídas

## ¿Qué es?

Es un endpoint AJAX minimalista. Su única función es marcar todas las notificaciones de un usuario como leídas cuando se llama con `?accion=marcar`. Lo usa el sidebar para actualizar el contador de la campana sin recargar la página.

---

## Archivo

```
Controllers/NotifController.php
```

---

## Cómo funciona

```php
// Responde siempre JSON
header('Content-Type: application/json');

// Verifica sesión
if (!isset($_SESSION['usuario'])) {
    echo json_encode(['ok' => false]); exit;
}

// Única acción disponible: 'marcar'
if ($accion === 'marcar') {
    UPDATE notificacion SET leida = 1 WHERE id_usuario_destino = :id
    echo json_encode(['ok' => true]);
}
```

---

## Quién lo llama

El sidebar (`views/layouts/sidebar.php`) tiene un JS que llama a este endpoint cuando el usuario abre el panel de notificaciones:

```js
fetch('../../Controllers/NotifController.php?accion=marcar')
    .then(r => r.json())
    .then(() => {
        // Oculta el badge rojo del contador
    });
```

---

## Diferencia con `CompraController::marcarLeidas()`

| | `NotifController` | `CompraController::marcarLeidas()` |
|---|---|---|
| Tipo | Endpoint AJAX (GET) | Método PHP estático |
| Responde | JSON | Nada (void) |
| Lo llama | JS del sidebar | `cliente_notificaciones.php` al cargar |
| Cuándo | Al abrir el panel del sidebar | Al abrir la página de notificaciones |

Ambos hacen el mismo UPDATE — son dos caminos distintos para el mismo resultado.

---

## Cosas a tener en cuenta

- **Solo tiene una acción** — si se llama con cualquier otro `?accion=`, responde `{'ok': false, 'error': 'Acción no reconocida'}`.
- **No filtra por tipo de rol** — cualquier usuario con sesión activa puede llamarlo, no solo clientes.
- **Marca TODAS las notificaciones** del usuario como leídas — no hay forma de marcar solo una.
