# 📄 `public/index.php` — Página de Aterrizaje

## ¿Qué es?
Es la **página pública del restaurante** — lo primero que ve cualquier visitante. No tiene lógica PHP de negocio, es pura presentación HTML con estilos y un pequeño script de navegación.

---

## Flujo de vida de la página

```
Visitante entra a /RetroRestaurant/public/index.php
        │
        ▼
  PHP activa errores (solo dev)
        │
        ▼
  HTML se renderiza con 5 secciones
        │
        ▼
  Usuario hace clic en "Reservaciones" o "Reservar Mesa"
        │
        ▼
  JS hace fade-out → redirige a /views/usuarios/login.php
```

## Las 5 secciones

### 1. `<nav>` — Barra de navegación
- Sticky (se queda arriba al hacer scroll)
- Links internos con anclas: `#inicio`, `#menu`, `#nosotros`
- Botón **"Reservaciones"** → redirige a `login.php`

### 2. `#inicio` — Hero
- Imagen de fondo de Unsplash con `opacity-50`
- Gradiente oscuro encima para legibilidad
- Botón **"Descubrir Menú"** → scroll suave a `#menu`

### 3. `#menu` — Platos Signature
- Grid de 3 tarjetas (Lomo Filet Mignon, Salmón Glaseado, Esfera de Chocolate)
- Cada tarjeta tiene: imagen, nombre, precio, descripción, botón
- Efecto hover: sube `translateY(-10px)` + sombra + borde dorado

### 4. `#nosotros` — Filosofía
- Imagen del chef + texto descriptivo
- Botón **"Reservar Mesa"** → redirige a `login.php`

### 5. `<footer>` — Pie de página
- Horarios, contacto, redes sociales, membresía VIP
- Todos los links de membresía apuntan a `login.php`

## Animaciones CSS

```css
/* Al cargar: aparece suavemente desde abajo */
body { animation: fadeIn 0.6s ease forwards; }

/* Al salir: desaparece hacia arriba */
body.fade-out { animation: fadeOut 0.4s ease forwards; }
```

## Script de navegación (el único JS)

```js
// Intercepta TODOS los links que no sean anclas (#)
document.querySelectorAll('a[href]').forEach(link => {
    link.addEventListener('click', e => {
        e.preventDefault();
        document.body.classList.add('fade-out'); // activa animación
        setTimeout(() => {
            window.location.href = href; // navega después de 400ms
        }, 400);
    });
});
```

## Relación con el resto del proyecto

```
index.php
    └── redirige a → views/usuarios/login.php
                            └── AuthController.php
                                    └── config/database.php → MySQL
```

El `index.php` **no toca la base de datos** ni ningún controlador. Es solo la vitrina. Todo el sistema real arranca desde `login.php`.

## `.htaccess` — Seguridad del servidor

Tres cosas importantes que hace:
1. **Bloquea listado de directorios** (`Options -Indexes`)
2. **Protege archivos sensibles** — `.sql`, `.md`, `.log`, `.env` devuelven 403
3. **Bloquea acceso directo a `/config/`** — nadie puede entrar a `database.php` por URL
