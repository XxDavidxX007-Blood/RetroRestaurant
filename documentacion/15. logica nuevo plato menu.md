# ➕ Nuevo Plato — Gestión de Menú

## ¿Qué hace?

Agrega un plato o bebida nuevo al menú del restaurante. A diferencia del inventario, este sí tiene imagen real, descripción y control de visibilidad para el cliente.

---

## Los archivos que participan

```
views/dashboard/admin_gestion_de_menu.php   →  botón + modal con el formulario
Controllers/MenuController.php              →  recibe el POST, sube la imagen, llama al modelo
models/Menu.php                             →  ejecuta los INSERT en la BD
```

---

## ¿Cómo se abre el formulario?

Un modal que aparece encima de la tabla:

```php
// Botón en la vista:
<button onclick="openModal('modalNuevoProducto')">
    + Agregar Plato al Menú
</button>

// JS que lo muestra/oculta:
function openModal(id)  { document.getElementById(id).classList.remove('hidden'); }
function closeModal(id) { document.getElementById(id).classList.add('hidden'); }
```

---

## Campos del formulario

| Campo | Tipo | Obligatorio | Ejemplo |
|---|---|---|---|
| Nombre del plato | texto | Sí | `Hamburguesa Doble` |
| Categoría | select | Sí | `Hamburguesas` |
| Precio de venta | número | Sí | `25000` |
| Descripción | textarea | No | `Con queso cheddar y papas` |
| Imagen del plato | archivo (jpg/png/webp) | No | `hamburguesa.jpg` |
| Mostrar en catálogo | checkbox | — | marcado = visible |

> El formulario usa `enctype="multipart/form-data"` porque sube un archivo.

## La subida de imagen

El controlador tiene un método dedicado para esto:

```php
private function subirImagen($campo = 'imagen_file') {
    if (empty($_FILES[$campo]['name'])) return null; // no subió nada → null

    $ext     = strtolower(pathinfo($file['name'], PATHINFO_EXTENSION));
    $allowed = ['jpg','jpeg','png','webp'];

    if (!in_array($ext, $allowed)) return null;  // extensión no permitida
    if ($file['size'] > 2 * 1024 * 1024) return null;  // más de 2MB

    $nombre  = 'menu_' . time() . '_' . mt_rand(100,999) . '.' . $ext;
    // Ejemplo: menu_1748000000_427.jpg

    move_uploaded_file($file['tmp_name'], __DIR__ . '/../img/menu/' . $nombre);
    return $nombre;
}
```

- Si no se sube imagen → `$imgNombre = null` → se guarda `''` en la BD
- Si se sube → se guarda el nombre del archivo (ej. `menu_1748000000_427.jpg`)
- Las imágenes se guardan en `img/menu/`

## Preview de imagen antes de guardar

El JS muestra la imagen seleccionada en tiempo real sin subir nada aún:

```js
function previewImagen(input, imgId, iconId, labelId) {
    const reader = new FileReader();
    reader.onload = function(e) {
        document.getElementById(imgId).src = e.target.result; // muestra la imagen
        document.getElementById(imgId).classList.remove('hidden');
        document.getElementById(iconId).classList.add('hidden'); // oculta el ícono
        document.getElementById(labelId).textContent = file.name; // muestra el nombre
    };
    reader.readAsDataURL(file); // lee el archivo localmente
}
```

## El flujo completo

```
1. Admin hace clic en "Agregar Plato al Menú"
2. Se abre el modal con el formulario vacío
3. Admin llena los datos, sube imagen (opcional), marca disponible
4. POST a admin_gestion_de_menu.php con accion=crear
5. Controlador llama a subirImagen() → guarda el archivo en img/menu/
6. Arma $datos con todos los campos
7. Llama a Menu::registrar($datos)
8. El modelo abre una transacción:
   → INSERT en producto (con es_menu=1, unidad='plato')
   → INSERT en inventario (cantidad=0, mínimo=0) — registro dummy para FK
9. Si OK → redirect ?success=creado
   Si falla → redirect ?error=crear
```

---

## ¿Por qué se inserta en inventario si es un plato del menú?

```php
// En Menu.php::registrar():
INSERT INTO inventario (id_producto, cantidad_actual, cantidad_minima, fecha_actualizacion)
VALUES (:id_producto, 0, 0, CURDATE())
```

La tabla `inventario` tiene una FK que apunta a `producto`. Si no se crea el registro, otras partes del sistema (pedidos, reportes) podrían lanzar errores de integridad referencial. Se inserta con `cantidad = 0` como registro de soporte — no aparece en la vista de inventario porque el filtro excluye los `es_menu = 1`.

## ¿Cómo detecta el controlador qué acción ejecutar?

```html
<input type="hidden" name="accion" value="crear">
```

```php
$accion = $_POST['accion'] ?? '';
if ($accion === 'crear')    $this->crear();
if ($accion === 'editar')   $this->editar();
if ($accion === 'eliminar') $this->eliminar();
```

---

## Cosas a tener en cuenta

- **Sin imagen** → la vista muestra el emoji `🍽️` por defecto.
- **El checkbox `disponible`** — si está marcado, el plato aparece en el catálogo del cliente. Si no, queda oculto pero no se borra.
- **No hay validación server-side** en el controlador — solo la del HTML (`required`, `min`).
- **Límite de imagen: 2MB** — validado tanto en JS (preview) como en el controlador (antes de mover el archivo).
