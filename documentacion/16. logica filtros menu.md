# 🔍 Filtros del Menú — Gestión de Menú

## ¿Qué hacen?

Permiten buscar y filtrar los platos de la tabla en tiempo real, sin recargar la página. Son 4 controles que trabajan juntos: buscador, categoría, disponibilidad y limpiar.

---

## Los archivos que participan

```
views/dashboard/admin_gestion_de_menu.php   →  HTML de los filtros + función JS filtrarTabla()
```

Solo vive en la vista. No hay controlador ni BD involucrados — todo ocurre en el navegador.

---

## Los 4 controles

| Control | Tipo | Filtra por |
|---|---|---|
| Buscar plato o bebida... | `input text` | Nombre del plato |
| Todas las categorías | `select` | Categoría (Hamburguesas, Bebidas, etc.) |
| Todos (Visibles/Ocultos) | `select` | Disponibilidad (`1` = visible, `0` = oculto) |
| Limpiar | `button` | Resetea los 3 anteriores |

---

## ¿Cómo funciona el filtrado?

Cada control llama a `filtrarTabla()` al cambiar (`onkeyup` / `onchange`):

```js
function filtrarTabla() {
    const busqueda      = document.getElementById('buscarMenu').value.toLowerCase();
    const categoria     = document.getElementById('filtroCategoria').value.toLowerCase();
    const disponibilidad = document.getElementById('filtroDisponibilidad').value;

    document.querySelectorAll('.menu-item').forEach(fila => {
        const matchNombre    = fila.dataset.nombre.includes(busqueda);
        const matchCategoria = categoria === 'todos' || fila.dataset.categoria === categoria;
        const matchDisponible = disponibilidad === 'todos' || fila.dataset.disponible === disponibilidad;

        fila.style.display = (matchNombre && matchCategoria && matchDisponible) ? '' : 'none';
        if (fila.style.display === '') visibles++;
    });

    document.getElementById('infoResultados').innerText = 'Mostrando ' + visibles + ' platos filtrados';
}
```

Las tres condiciones deben cumplirse al mismo tiempo. Si cualquiera falla, la fila se oculta.

---

## ¿Cómo sabe la función qué datos tiene cada fila?

Los datos se guardan como atributos `data-*` en cada `<tr>` cuando PHP genera la tabla:

```php
<tr class="menu-item"
    data-nombre="<?= strtolower(htmlspecialchars($item['nombre'])) ?>"
    data-categoria="<?= strtolower(htmlspecialchars($item['categoria'])) ?>"
    data-disponible="<?= $item['disponible'] ?>">  <!-- 1 o 0 -->
```

---

## El filtro de disponibilidad — diferencia con inventario

En inventario el filtro de estado tiene 3 valores (`stock`, `bajo`, `sin`). En menú solo hay 2:

```html
<option value="todos">Todos (Visibles/Ocultos)</option>
<option value="1">Visibles (Catálogo)</option>   <!-- data-disponible="1" -->
<option value="0">Ocultos (Agotados)</option>    <!-- data-disponible="0" -->
```

El `data-disponible` viene directo del campo `disponible` de la BD (`1` o `0`), sin transformación.

---

## ¿Cómo funciona "Limpiar"?

Resetea los tres controles y vuelve a llamar a `filtrarTabla()` para mostrar todo:

```js
function limpiarFiltros() {
    document.getElementById('buscarMenu').value          = '';
    document.getElementById('filtroCategoria').value     = 'todos';
    document.getElementById('filtroDisponibilidad').value = 'todos';
    filtrarTabla();
}
```

---

## ¿Cómo se cargan las categorías del select?

Vienen de la BD, no están escritas a mano:

```php
// El controlador las trae:
$categorias = $datosVista['categorias'];

// La vista las pinta:
<?php foreach($categorias as $cat): ?>
    <option value="<?= strtolower($cat['nombre_categoria']) ?>">
        <?= htmlspecialchars($cat['nombre_categoria']) ?>
    </option>
<?php endforeach; ?>
```

El `value` va en minúsculas para que coincida con el `data-categoria` de las filas.

---

## El contador de resultados

- **Al cargar la página** → PHP pinta `"Mostrando X platos"` con `count($menu)`
- **Al filtrar** → JS actualiza a `"Mostrando X platos filtrados"`

---

## Cosas a tener en cuenta

- **Todo ocurre en el navegador** — no hay petición al servidor al filtrar. Es instantáneo.
- **Los filtros se combinan** — puedes buscar "burger" + categoría "Hamburguesas" + estado "Visibles" al mismo tiempo.
- **Si agregas una categoría nueva en la BD**, aparece automáticamente en el select sin tocar el código.
- **El filtro de disponibilidad usa `1` y `0`** como strings al comparar con `dataset.disponible` — PHP renderiza el número y JS lo compara como string, lo que funciona correctamente.
