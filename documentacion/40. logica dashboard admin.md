# 📊 Dashboard del Admin

## ¿Qué es?

Es la página de inicio del administrador. Muestra el resumen completo del negocio en tiempo real: ventas, pedidos, clientes, gráficos de tendencia, pedidos recientes, platos más vendidos, reservas del día y domicilios recientes.

---

## Archivos involucrados

```
views/dashboard/admin_dashboard.php    →  vista completa
Controllers/DashboardController.php    →  obtiene y prepara todos los datos
models/Dashboard.php                   →  todas las consultas SQL
```

---

## Acceso

Solo rol 1 (admin). Cualquier otro → redirige a `login.php`.

---

## Flujo al cargar

```php
$controller = new DashboardController();
$datos      = $controller->obtenerDatosVista();
extract($datos); // expone todas las variables a la vista
```

El controlador llama a cada método del modelo envuelto en `safe()` — si cualquier query falla, devuelve el valor por defecto en lugar de romper la página:

```php
private function safe(callable $fn, $default) {
    try { return $fn(); } catch (Exception $e) { return $default; }
}
```

## Las 5 stat cards

| Card | Dato | Variación |
|---|---|---|
| 💰 Ventas del día | Suma de facturas de hoy | % vs ayer |
| 🧾 Pedidos del día | Count de pedidos de hoy | % vs ayer |
| 👤 Clientes atendidos | Clientes únicos con pedido hoy | % vs ayer |
| 🍽️ Platos más vendidos | Count de platos distintos vendidos hoy | — |
| 📦 Productos en inventario | Total de productos con registro en inventario | — |

La variación se calcula con:
```php
private function variacion($hoy, $ayer) {
    if ($ayer == 0) return $hoy > 0 ? 100 : 0;
    return round((($hoy - $ayer) / $ayer) * 100, 1);
}
```

## Los 2 gráficos (Chart.js)

### Gráfico de línea — Ventas de los últimos 7 días

PHP construye los datos para los últimos 7 días, rellenando con 0 los días sin ventas:

```php
$ventasSemana = $this->dashboardModel->getVentasSemana();
$mapaVentas   = array_column($ventasSemana, 'total', 'dia'); // ['2026-05-14' => 85000, ...]

for ($i = 6; $i >= 0; $i--) {
    $fecha = date('Y-m-d', strtotime("-$i days"));
    $chartLabels[] = date('d M', strtotime($fecha)); // '12 May'
    $chartValues[] = isset($mapaVentas[$fecha]) ? (float)$mapaVentas[$fecha] : 0;
}
```

Los datos se inyectan en JS como JSON:
```js
labels: <?= $chartLabels ?>,  // ["12 May", "13 May", ...]
data:   <?= $chartData ?>     // [85000, 0, 120000, ...]
```

Color dorado (`#c5a059`), área rellena con opacidad 10%, tensión 0.4 (curva suave).

### Gráfico de dona — Pedidos por estado

```php
$paleta = ['#F59E0B','#3B82F6','#10B981','#8B5CF6','#EF4444','#06B6D4','#F97316'];
```

## Las 4 tablas de datos

### Reservas de hoy (dentro de la columna del donut)
Query directa en la vista (no pasa por el modelo):
```sql
SELECT r.hora_reserva, r.numero_personas, u.nombre, u.apellidos,
       er.nombre_estado, m.numero_mesa
FROM reserva r
JOIN cliente c ON r.id_cliente = c.id_cliente
JOIN usuario u ON c.id_usuario = u.id_usuario
JOIN estado_reserva er ON r.id_estado_reserva = er.id_estado_reserva
LEFT JOIN mesa m ON r.id_mesa = m.id_mesa
WHERE r.fecha_reserva = CURDATE()
ORDER BY r.hora_reserva ASC
LIMIT 5
```

### Pedidos recientes
Últimos pedidos con cliente, tipo (mesa/domicilio), total y estado con badge de color. Link "Ver todos" → `admin_pedidos.php`.

### Platos más vendidos
Platos ordenados por cantidad vendida con categoría, unidades e ingresos. Link "Ver reporte" → `admin_reportes.php`.

### Domicilios recientes
Últimos domicilios con cliente, teléfono, fecha, total y estado. Incluye un badge con el conteo de domicilios de hoy. Link "Ver todos" → `admin_domicilios.php`.

## Cosas a tener en cuenta

- **Todo está en `safe()`** — si cualquier query falla, el dashboard carga con ceros en lugar de mostrar un error.
- **Las reservas de hoy se consultan directamente en la vista**, no en el modelo — es la única query que no pasa por `DashboardController`.
- **Chart.js se carga desde CDN** al final de la vista.
- **No hay actualización en tiempo real** — los datos son una foto del momento en que se cargó la página. Para ver datos nuevos hay que recargar.
- **El botón `⋮`** en la tabla de pedidos recientes no tiene acción implementada — es solo visual.
