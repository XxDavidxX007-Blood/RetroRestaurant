# 🍽️ Gestión de Menú — Vista General

## ¿Qué es?

Es el módulo donde el admin administra los platos y bebidas que los clientes ven en el catálogo. Desde aquí se crean, editan y eliminan platos, y se controla si están visibles o no.

---

## Los archivos que participan

```
views/dashboard/admin_gestion_de_menu.php   →  vista: tabla, filtros, modales, JS
Controllers/MenuController.php              →  recibe POST/GET y coordina acciones
models/Menu.php                             →  consultas SQL a la BD
```

---

## Flujo general

```
Admin entra a admin_gestion_de_menu.php
        │
        ├── Verifica sesión (solo rol admin)
        │       └── Si no → redirige a login.php
        │
        ├── Instancia MenuController
        │       ├── manejarPeticion() → procesa POST si hay acción
        │       └── obtenerDatosVista() → trae platos y categorías de la BD
        │
        └── Renderiza la vista con:
                ├── 3 tarjetas de estadísticas
                ├── Filtros (buscador + categoría + disponibilidad)
                ├── Tabla de platos
                └── 3 modales (crear / editar / eliminar)
```

---

## Las 3 estadísticas

Calculadas en PHP antes de renderizar, con los datos que ya trajo el modelo:

| Tarjeta | Qué muestra | Cómo se calcula |
|---|---|---|
| Total Platos | Cantidad de platos en el menú | `count($menu)` |
| Platos Ocultos | Platos con `disponible = 0` | Loop contando los que no están visibles |
| Precio Promedio | Promedio de todos los precios | `suma de precios / total platos` |

---

## Diferencia clave con Inventario

| Inventario | Menú |
|---|---|
| Insumos internos (harina, leche, etc.) | Platos visibles para el cliente |
| `es_menu = 0` en la BD | `es_menu = 1` en la BD |
| No tiene imagen real | Tiene imagen subida por el admin |
| No tiene descripción | Tiene descripción visible al cliente |
| No tiene disponibilidad | Tiene toggle visible/oculto |
| Tiene exportar CSV | No tiene exportar |

Ambos usan la misma tabla `producto` en la BD — se distinguen por la columna `es_menu`.

---

## Relación con el resto del proyecto

```
admin_gestion_de_menu.php
        ├── MenuController.php → Menu.php → tabla producto (es_menu=1)
        └── Los platos creados aquí aparecen en:
                └── views/dashboard/cliente_catalogo.php  (lo que ve el cliente)
```
