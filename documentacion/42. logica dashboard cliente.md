# 🏠 Dashboard del Cliente

## ¿Qué es?

Es la página de inicio del cliente al iniciar sesión. Muestra un saludo, 4 tarjetas de acceso rápido con conteos personalizados, las próximas reservas, una sección de "Retro Puntos" y una barra de características del restaurante.

---

## Archivo

```
views/dashboard/cliente.php
```

---

## Acceso

Solo rol 3 (cliente). Cualquier otro → redirige a `login.php`.

---

## Lo que hace al cargar

Primero obtiene el `id_cliente` del usuario en sesión, luego ejecuta 4 conteos y una query de reservas próximas. Todo está envuelto en `try/catch` — si la BD falla, muestra ceros en lugar de romper la página:

```php
// 1. Obtiene id_cliente
SELECT id_cliente FROM cliente WHERE id_usuario = :id LIMIT 1

// 2. Conteos personalizados del cliente
$totalReservas   = COUNT(*) FROM reserva WHERE id_cliente=X AND fecha_reserva >= CURDATE()
$totalPedidos    = COUNT(*) FROM pedido WHERE id_cliente=X
$totalDomicilios = COUNT(*) FROM pedido p JOIN tipo_pedido tp ... WHERE id_cliente=X AND tipo LIKE '%domicilio%'

// 3. Total de platos en el menú (no filtrado por cliente)
$totalMenu = COUNT(*) FROM producto

// 4. Próximas reservas (máximo 5, ordenadas por fecha ASC)
SELECT fecha_reserva, hora_reserva, numero_personas, estado, numero_mesa
FROM reserva r
JOIN estado_reserva er ...
LEFT JOIN mesa m ...
WHERE r.id_cliente = :id
ORDER BY fecha_reserva ASC, hora_reserva ASC
LIMIT 5
```

**Compatibilidad de columna:** antes de la query de reservas, verifica si la columna se llama `numero_personas` o `numero_usuarios` con un `SHOW COLUMNS`:
```php
$testCol = $db->query("SHOW COLUMNS FROM reserva LIKE 'numero_personas'")->fetch();
if (!$testCol) $colPersonas = 'numero_usuarios';
```

## Las 5 secciones de la vista

### 1. Bienvenida
Saludo con el nombre del cliente y un buscador decorativo (no funcional — no tiene acción ni JS conectado):
```php
¡Bienvenido, <?= $usuario['nombre'] ?>! 👋
¿Qué quieres disfrutar hoy?
```

### 2. Las 4 tarjetas oscuras

Grid de 4 columnas con tarjetas de fondo oscuro (`#1a1f2e`). Cada una es un link a su módulo:

| Tarjeta | Dato mostrado | Destino |
|---|---|---|
| 📅 Mis Reservas | Reservas próximas (desde hoy) | `cliente_reservas.php` |
| 🧾 Mis Pedidos | Total histórico de pedidos | `cliente_pedidos.php` |
| 🛵 Domicilios | Total de pedidos tipo domicilio | `cliente_domicilios.php` |
| 🍽️ Menú | Total de productos en la BD | `cliente_catalogo.php` |

**Animación de contador:** al entrar en el viewport, los números cuentan desde 0 hasta el valor real usando `IntersectionObserver`:
```js
document.querySelectorAll('.card-big').forEach(el => {
    const num = parseInt(el.textContent);
    let s = 0, step = Math.ceil(num / 50);
    const t = setInterval(() => {
        s += step;
        if (s >= num) { el.textContent = num + suf; clearInterval(t); }
        else el.textContent = s + suf;
    }, 16); // ~60fps
});
```

**Efecto hover:** el ícono hace `scale(1.2) rotate(-5deg)` y el borde se vuelve dorado.

### 3. Reservas próximas

Tabla con las próximas 5 reservas del cliente (fecha, hora, mesa, personas, estado con badge de color). Si no tiene reservas → mensaje vacío con link a crear una.

La función `badgeR()` devuelve colores según el estado:
```php
'confirmada' → verde | 'pendiente' → amarillo | 'cancelada' → rojo | 'completada' → morado
```

### 4. Retro Puntos

Sección decorativa con sistema de puntos **hardcodeado** (no viene de la BD):
```php
$puntos   = 1250;   // fijo, no se calcula
$nivel    = 'Oro';  // calculado: >= 1000 → Oro, >= 500 → Plata, else Bronce
$meta     = 2000;
$progreso = min(100, round($puntos / $meta * 100)); // 62%
```

La barra de progreso se anima con CSS al entrar en el viewport:
```js
const fill = document.querySelector('.puntos-fill');
// IntersectionObserver → fill.style.width = '62%' con transición de 1.4s
```

El botón "Ver beneficios" no tiene acción — es solo visual.

### 5. Barra de características

4 íconos con textos fijos: Pago seguro, Atención 24/7, Envíos rápidos, Calidad garantizada. Puramente decorativo.

## Flujo completo

```
Cliente inicia sesión → AuthController asigna sesión con id_rol=3
        │
        └── Redirige a cliente.php
                │
                ├── Verifica rol 3 → OK
                ├── Obtiene id_cliente
                ├── Ejecuta 4 conteos + query de reservas próximas
                └── Renderiza: saludo + 4 tarjetas + reservas + puntos + características
```

---

## Cosas a tener en cuenta

- **El buscador del header no funciona** — tiene el input pero no hay JS ni acción conectada. Es decorativo.
- **Los Retro Puntos son hardcodeados** — `$puntos = 1250` está fijo en el código. No hay tabla de puntos en la BD ni lógica de acumulación implementada.
- **`$totalMenu` cuenta todos los productos**, no solo los del menú (`es_menu=1`). Puede mostrar un número mayor al real.
- **Las reservas próximas** solo muestran las 5 más cercanas — para ver todas hay un link "Ver todas" que va a `cliente_reservas.php`.
- **Todo está en `try/catch`** — si la BD no responde, el dashboard carga igual con todos los conteos en 0.
