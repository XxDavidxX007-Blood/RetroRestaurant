# 👨‍💼 Panel de Reservas — Admin/Empleado

## ¿Qué hace?

Muestra todas las reservas del restaurante con KPIs, filtros por tab de tiempo y fecha, tabla paginada, y permite crear, editar y eliminar cualquier reserva.

---

## Archivos involucrados

```
views/dashboard/admin_reservas.php   →  vista completa
Controllers/ReservaController.php    →  lógica: KPIs, filtros, CRUD
models/Reserva.php                   →  consultas SQL
```

---

## Las 5 KPI cards

| Card | Qué muestra | Cómo se calcula |
|---|---|---|
| Reservas hoy | Total del día + % vs ayer | `COUNT WHERE fecha = CURDATE()` |
| Reservas mañana | Total del día siguiente + % vs hoy | `COUNT WHERE fecha = CURDATE()+1` |
| Confirmadas | Reservas confirmadas hoy | `COUNT WHERE estado='confirmada' AND fecha=CURDATE()` |
| Pendientes | Reservas pendientes hoy | `COUNT WHERE estado='pendiente' AND fecha=CURDATE()` |
| Canceladas | Reservas canceladas hoy | `COUNT WHERE estado='cancelada' AND fecha=CURDATE()` |

Los KPIs de estado solo cuentan reservas **de hoy**, no históricas.

## Los filtros — tabs de tiempo + fecha

### Tabs rápidos
```
Todas | Hoy | Mañana | Esta semana
```

Cada tab es un link que recarga con `?tab=valor`. El controlador traduce el tab a una fecha efectiva:

```php
if ($filtro_tab === 'hoy')    $fecha_efectiva = date('Y-m-d');
if ($filtro_tab === 'manana') $fecha_efectiva = date('Y-m-d', strtotime('+1 day'));
if ($filtro_tab === 'semana') $fecha_efectiva = ''; // sin filtro de fecha exacta
```

"Esta semana" no filtra por fecha — muestra todas las reservas sin importar la fecha.

### Filtro de fecha manual
Un `<input type="date">` que al cambiar ejecuta:

```js
function aplicarFecha(val) {
    const url = new URL(window.location.href);
    val ? url.searchParams.set('fecha', val) : url.searchParams.delete('fecha');
    url.searchParams.set('pagina', 1);
    window.location.href = url.toString();
}
```

Si el admin escribe una fecha manual, tiene prioridad sobre el tab.

### Orden de la tabla
Las reservas se ordenan por `fecha_reserva ASC, hora_reserva ASC` — las más próximas primero.

## Los 3 modales

### Modal Crear
Campos: Cliente (opcional), Mesa, Personas, Fecha, Hora, Estado.

- El cliente es opcional — se puede crear una reserva sin asignar cliente (`id_cliente = null`)
- La fecha por defecto es hoy
- La hora por defecto es 12:00

```html
<form action="admin_reservas.php" method="POST">
    <input type="hidden" name="accion" value="crear">
    <!-- campos -->
</form>
```

### Modal Editar
Se abre con JS que pre-llena los campos con los datos de la fila:

```js
function abrirEditar(r) {
    document.getElementById('edit_id').value       = r.id_reserva;
    document.getElementById('edit_personas').value = r.numero_personas;
    document.getElementById('edit_fecha').value    = r.fecha_reserva;
    document.getElementById('edit_hora').value     = r.hora_reserva.substring(0, 5); // "HH:MM"

    // Mesa: busca por texto que empiece con "Mesa X"
    const sm = document.getElementById('edit_mesa');
    for (let i = 0; i < sm.options.length; i++) {
        if (sm.options[i].text.startsWith('Mesa ' + r.numero_mesa)) {
            sm.selectedIndex = i; break;
        }
    }

    // Estado: busca por value (id numérico)
    const se = document.getElementById('edit_estado');
    for (let i = 0; i < se.options.length; i++) {
        if (se.options[i].value == r.id_estado_reserva) {
            se.selectedIndex = i; break;
        }
    }

    document.getElementById('modalEditar').classList.remove('hidden');
}
```

A diferencia del cliente, el admin **sí puede cambiar el estado** desde el modal de edición.

### Modal Eliminar
Solo guarda el ID y envía el formulario:

```js
function abrirEliminar(id) {
    document.getElementById('del_id').value = id;
    document.getElementById('modalEliminar').classList.remove('hidden');
}
```

No hay restricción de estado — el admin puede eliminar cualquier reserva.

## El flujo CRUD en el controlador

```php
// ReservaController::manejarPeticion()
switch ($accion) {
    case 'crear':   $this->crear();   break;
    case 'editar':  $this->editar();  break;
    case 'eliminar':$this->eliminar();break;
}
// Todos redirigen con ?success=X o ?error=mensaje
```

```sql
-- crear:
INSERT INTO reserva (id_cliente, id_mesa, fecha_reserva, hora_reserva, numero_personas, id_estado_reserva)
VALUES (...)

-- editar:
UPDATE reserva SET id_mesa=:id_mesa, fecha_reserva=:fecha, hora_reserva=:hora,
                   numero_personas=:personas, id_estado_reserva=:estado
WHERE id_reserva = :id

-- eliminar:
DELETE FROM reserva WHERE id_reserva = :id
```

## Paginación

10 reservas por página. Los links preservan todos los filtros activos con `http_build_query(array_merge($_GET, ['pagina' => X]))`.

---

## Cosas a tener en cuenta

- **No hay validación de disponibilidad de mesa** — se puede crear dos reservas para la misma mesa a la misma hora sin que el sistema lo detecte.
- **El tab "Esta semana" no filtra por semana** — muestra todas las reservas sin filtro de fecha. Es un comportamiento pendiente de implementar.
- **El admin puede eliminar cualquier reserva** sin importar el estado — no hay confirmación de negocio, solo el modal de "¿estás seguro?".
- **La hora se recorta a 5 caracteres** (`substring(0,5)`) al pre-llenar el modal — convierte `"12:00:00"` a `"12:00"` para que el `<input type="time">` lo acepte.
