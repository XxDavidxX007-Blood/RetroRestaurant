# 🧑‍🍳 Dashboard del Empleado

## ¿Qué es?

Es la página de inicio del empleado al iniciar sesión. Muestra un saludo, 3 KPIs del día y 3 accesos rápidos a los módulos que el empleado puede gestionar. No tiene lógica compleja — es solo una vista de resumen.

---

## Archivo

```
views/dashboard/empleado.php
```

---

## Acceso

Solo rol 2 (empleado). Si entra alguien con otro rol → redirige a `login.php`:

```php
if (!in_array($_SESSION['usuario']['id_rol'], [2, '2', 'empleado'])) {
    header("Location: .../views/usuarios/login.php");
    exit;
}
```

---

## Lo que hace al cargar

Instancia los 3 modelos directamente y llama a un método de cada uno:

```php
$db = (new database())->conectar();

$reservasHoy   = (new Reserva($db))->getReservasHoy();
$pedidosHoy    = (new Pedido($db))->getPedidosHoy();
$domiciliosHoy = (new Domicilio($db))->getDomiciliosHoy();
```

Cada método hace un `COUNT` simple sobre la fecha de hoy:

```sql
-- Reserva::getReservasHoy()
SELECT COUNT(*) FROM reserva WHERE DATE(fecha_reserva) = CURDATE()

-- Pedido::getPedidosHoy()
SELECT COUNT(*) FROM pedido WHERE DATE(fecha_pedido) = CURDATE()

-- Domicilio::getDomiciliosHoy()
SELECT COUNT(*) FROM pedido p
JOIN tipo_pedido tp ON p.id_tipo_pedido = tp.id_tipo_pedido
WHERE DATE(p.fecha_pedido) = CURDATE()
  AND (tp.nombre_tipo LIKE '%domicilio%' OR tp.nombre_tipo LIKE '%delivery%')
```

## Las 3 secciones de la vista

### 1. Bienvenida
Tarjeta con el nombre del empleado tomado de la sesión y la fecha actual:

```php
Bienvenido, <?= htmlspecialchars($usuario['nombre']) ?> 👋
Panel de empleado — <?= date('d \d\e F, Y') ?>
// Ejemplo: "15 de mayo, 2026"
```

### 2. KPIs del día

| Card | Dato | Color |
|---|---|---|
| 📅 Reservas hoy | Total de reservas del día | Morado |
| 🧾 Pedidos hoy | Total de pedidos del día (todos los tipos) | Amarillo |
| 🛵 Domicilios hoy | Total de pedidos tipo domicilio del día | Verde |

Los 3 números se calculan en PHP antes de renderizar — no hay AJAX ni actualización en tiempo real.

### 3. Accesos rápidos

3 tarjetas que son links directos a los módulos del empleado:

| Tarjeta | Destino | Color hover |
|---|---|---|
| Reservas | `admin_reservas.php` | Borde morado |
| Pedidos | `admin_pedidos.php` | Borde amarillo |
| Domicilios | `admin_domicilios.php` | Borde verde |

Cada tarjeta tiene un efecto hover: el ícono hace `scale(1.1)` y el borde cambia de color.

---

## Flujo completo

```
Empleado inicia sesión → AuthController asigna sesión con id_rol=2
        │
        └── Redirige a empleado.php
                │
                ├── Verifica rol 2 → OK
                ├── Instancia Reserva, Pedido, Domicilio
                ├── Obtiene 3 conteos del día
                └── Renderiza: saludo + KPIs + accesos rápidos
```

---

## Qué puede hacer el empleado desde aquí

El dashboard solo muestra números y links. Las acciones reales están en los módulos a los que apuntan los accesos rápidos:

- **Reservas** → puede ver y gestionar reservas (`admin_reservas.php` acepta rol 1 y 2)
- **Pedidos** → puede ver y cambiar estados de pedidos (`admin_pedidos.php` acepta rol 1 y 2)
- **Domicilios** → puede ver y cambiar estados de domicilios (`admin_domicilios.php` acepta rol 1 y 2)

El empleado **no tiene acceso** a: inventario, menú, reportes, usuarios ni notificaciones — esos módulos solo aceptan rol 1 (admin).

---

## Cosas a tener en cuenta

- **Los KPIs no se actualizan solos** — si llega un pedido nuevo mientras el empleado tiene el dashboard abierto, el número no cambia hasta que recargue la página.
- **El dashboard es minimalista a propósito** — el empleado solo necesita ver el resumen del día y navegar rápido a su trabajo. No tiene gráficos ni historial.
- **Usa los mismos modelos que el admin** — `Reserva`, `Pedido` y `Domicilio` son compartidos. No hay modelos exclusivos del empleado.
