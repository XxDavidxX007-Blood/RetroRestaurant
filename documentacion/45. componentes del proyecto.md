# 🧩 Componentes del Proyecto — RetroRestaurant

Todos los componentes externos e internos que usa el proyecto, qué hacen y dónde se usan.

## 1. Librerías externas (CDN)

### Tailwind CSS
- **Qué es:** Framework de CSS utilitario. En lugar de escribir CSS propio, se usan clases directamente en el HTML.
- **Versión:** CDN (última estable)
- **Dónde se carga:** `views/layouts/header.php` y `public/index.php`
- **Cómo se usa:**
  ```html
  <div class="bg-white rounded-2xl shadow p-6 flex items-center gap-4">
  ```
- **Configuración personalizada** (en `index.php` y `header.php`):
  ```js
  tailwind.config = {
      theme: { extend: { colors: {
          retro: {
              gold:    '#c5a059',
              dark:    '#0a0a0a',
              red:     '#e53e3e',
              subtle:  '#f5f5f5'
          }
      }}}
  }
  ```
  Esto agrega clases como `bg-retro-gold`, `text-retro-dark`, `border-retro-red`.

---

### Font Awesome 6
- **Qué es:** Librería de íconos vectoriales (SVG/CSS).
- **Dónde se carga:** `views/layouts/header.php`
- **Cómo se usa:**
  ```html
  <i class="fas fa-wine-glass"></i>       <!-- sólido -->
  <i class="far fa-heart"></i>            <!-- outline -->
  <i class="fab fa-instagram"></i>        <!-- marca -->
  ```

### Google Fonts
- **Qué es:** Servicio de tipografías web de Google.
- **Dónde se carga:** `views/layouts/header.php` y `public/index.php`
- **Fuentes usadas:**

  | Fuente | Clase Tailwind | Para qué |
  |---     |---             |---       |
  | `Playfair Display` | `font-heading` | Títulos, nombres de platos, encabezados |
  | `Montserrat` | `font-body` | Texto general, párrafos, labels |

  ```html
  <h1 class="font-heading font-bold">Gestión de Inventarios</h1>
  <p class="font-body text-gray-500">Administra tus insumos</p>
  ```

---

### Chart.js
- **Qué es:** Librería JavaScript para gráficos interactivos.
- **Versión:** CDN (`cdn.jsdelivr.net/npm/chart.js`)
- **Dónde se usa:** `admin_dashboard.php` y `admin_reportes.php`
- **Tipos de gráfico usados:**

  | Tipo | Dónde | Qué muestra |
  |---   |---    |---          |      
  | `line` | Dashboard admin | Ventas de los últimos 7 días |
  | `doughnut` | Dashboard admin | Pedidos por estado |
  | `doughnut` | Reportes | Valor de inventario por categoría |
  | `pie` | Reportes | Estado general del stock |

- **Patrón de uso:** PHP inyecta los datos como JSON directamente en el JS:
  ```php
  const labels = <?= json_encode($chartLabels) ?>;
  const data   = <?= json_encode($chartData) ?>;
  ```

---

### SweetAlert2
- **Qué es:** Librería para modales de alerta bonitos (reemplaza el `alert()` nativo del navegador).
- **Dónde se carga:** `views/layouts/header.php`
- **Cómo se usa:** El sistema de alertas del proyecto guarda un array en `$_SESSION['alert']` y el header lo detecta y dispara el SweetAlert:
  ```php
  // En cualquier controlador:
  $_SESSION['alert'] = [
      'icon'  => 'success',   // success, error, warning, info
      'title' => 'Éxito',
      'text'  => 'Operación realizada correctamente.'
  ];
  ```
  ```js
  // En header.php:
  Swal.fire({ icon: 'success', title: 'Éxito', text: '...' });
  ```
- **Dónde se genera la alerta:** En `AuthController`, `UsuarioController`, `AdminUsuarioController`, `PerfilController`.

## 2. Componentes PHP internos

### `config/database.php` — Conexión a la BD
- Clase `Database` con método `conectar()` que devuelve una instancia PDO.
- Alias `database` (minúscula) para compatibilidad con código antiguo.
- Configuración: host, nombre de BD, usuario y contraseña.
- Lanzar `RuntimeException` si la conexión falla.

```php
$db = (new Database())->conectar(); // uso estándar
$db = (new database())->conectar(); // alias compatible
```

---

### `views/layouts/header.php` — Cabecera HTML
- Abre el `<html>`, carga todas las librerías externas (Tailwind, Font Awesome, Google Fonts, SweetAlert2, Chart.js).
- Configura Tailwind con los colores `retro-*`.
- Detecta `$_SESSION['alert']` y dispara SweetAlert si existe.
- Renderiza la barra superior del dashboard (nombre del usuario, campana de notificaciones, foto de perfil).
- La campana muestra un badge rojo con el conteo de notificaciones no leídas.

---

### `views/layouts/sidebar.php` — Menú lateral
- Menú de navegación lateral que cambia según el rol del usuario:
  - **Admin (rol 1):** Dashboard, Pedidos, Reservas, Domicilios, Inventario, Menú, Reportes, Usuarios
  - **Empleado (rol 2):** Dashboard, Pedidos, Reservas, Domicilios
  - **Cliente (rol 3):** Dashboard, Catálogo, Mis Pedidos, Mis Reservas, Domicilios, Notificaciones
- Resalta el link activo comparando la URL actual con `$_SERVER['SCRIPT_NAME']`.
- Tiene un botón de "Cerrar sesión" que llama a `AuthController` con `accion=logout`.

---

### `views/layouts/footer.php` — Pie de página
- Cierra los tags `</div>`, `</main>`, `</body>`, `</html>`.
- Puede incluir scripts JS globales al final del body.

## 3. Patrón de modales

Todos los modales del proyecto siguen el mismo patrón con Tailwind:

```html
<!-- El modal empieza oculto con la clase 'hidden' -->
<div id="miModal" class="fixed inset-0 z-50 hidden flex items-center justify-center bg-black/50 backdrop-blur-sm">
    <div class="bg-white rounded-2xl shadow-2xl w-full max-w-lg overflow-hidden">
        <!-- contenido -->
    </div>
</div>
```

```js
// Abrir:
document.getElementById('miModal').classList.remove('hidden');

// Cerrar:
document.getElementById('miModal').classList.add('hidden');
```

**Excepción:** `cliente_reservas.php` y `cliente_catalogo.php` usan clases CSS propias (`modal-bg` / `.show`) en lugar de `hidden`.

## 4. Patrón de badges de estado

Todos los módulos tienen un método estático `badgeEstado()` en su controlador que devuelve colores consistentes:

```php
// Ejemplo de PedidoController::badgeEstado():
$map = [
    'pendiente'      => ['bg'=>'#FEF3C7', 'color'=>'#D97706', 'dot'=>'#F59E0B'],
    'en_preparacion' => ['bg'=>'#DBEAFE', 'color'=>'#2563EB', 'dot'=>'#3B82F6'],
    'listo'          => ['bg'=>'#D1FAE5', 'color'=>'#059669', 'dot'=>'#10B981'],
    'entregado'      => ['bg'=>'#EDE9FE', 'color'=>'#7C3AED', 'dot'=>'#8B5CF6'],
    'cancelado'      => ['bg'=>'#FEE2E2', 'color'=>'#DC2626', 'dot'=>'#EF4444'],
];
```

Se usa en la vista así:
```php
$b = PedidoController::badgeEstado($p['estado']);
echo "<span style='background:{$b['bg']};color:{$b['color']};'>{$b['label']}</span>";
```

**Colores estándar del proyecto:**

| Estado | Color | Hex |
|---|---|---|
| Pendiente | Amarillo | `#D97706` |
| En preparación / Activo | Azul | `#2563EB` |
| Listo / Confirmado | Verde | `#059669` |
| Entregado / Completado | Morado | `#7C3AED` |
| Cancelado / Sin stock | Rojo | `#DC2626` |
| No asistió / Neutro | Gris | `#6B7280` |

## 5. Patrón de dropdowns de acciones (`⋮`)

Usado en inventario, menú, pedidos admin y domicilios:

```html
<!-- Botón que abre el dropdown -->
<button onclick="toggleDropdown(<?= $item['id'] ?>)" class="dropdown-container">
    <i class="fas fa-ellipsis-v"></i>
</button>

<!-- Dropdown oculto por defecto -->
<div id="dropdown-<?= $item['id'] ?>" class="hidden absolute right-0 mt-2 w-48 bg-white rounded-md shadow-lg z-50">
    <a onclick="abrirModalEditar(...)">Editar</a>
    <a onclick="abrirModalEliminar(...)">Eliminar</a>
</div>
```

```js
function toggleDropdown(id) {
    // Cierra todos los otros
    document.querySelectorAll('[id^="dropdown-"]').forEach(el => {
        if (el.id !== 'dropdown-' + id) el.classList.add('hidden');
    });
    document.getElementById('dropdown-' + id).classList.toggle('hidden');
}

// Clic fuera → cierra todos
window.onclick = function(e) {
    if (!e.target.closest('.dropdown-container')) {
        document.querySelectorAll('[id^="dropdown-"]').forEach(el => el.classList.add('hidden'));
    }
}
```

## 6. Patrón de filtros con tabs + fecha

Usado en pedidos, reservas, domicilios y mis pedidos del cliente:

```html
<!-- Tabs de estado -->
<a href="?estado=pendiente" class="border-b-2 border-retro-red text-retro-red font-bold">Pendiente</a>
<a href="?estado=todos"     class="border-b-2 border-transparent text-gray-500">Todos</a>

<!-- Filtro de fecha -->
<input type="date" onchange="aplicarFecha(this.value)">
```

```js
function aplicarFecha(val) {
    const url = new URL(window.location.href);
    val ? url.searchParams.set('fecha', val) : url.searchParams.delete('fecha');
    url.searchParams.set('pagina', 1); // resetea paginación
    window.location.href = url.toString();
}
```

## 10. Sistema de alertas con `$_SESSION['alert']`

Flujo completo:

```
Controlador guarda alerta en sesión
        │
        └── header.php la detecta y dispara SweetAlert
                │
                └── Si tiene 'redirect' → redirige automáticamente después de cerrar
```

```php
// Estructura del array:
$_SESSION['alert'] = [
    'icon'     => 'success',          // success | error | warning | info
    'title'    => 'Título',
    'text'     => 'Mensaje detallado',
    'redirect' => 'login.php'         // opcional — redirige al cerrar
];
```

```js
// En header.php:
Swal.fire({
    icon: '<?= $alert["icon"] ?>',
    title: '<?= $alert["title"] ?>',
    text: '<?= $alert["text"] ?>'
}).then(() => {
    <?php if (isset($alert['redirect'])): ?>
    window.location.href = '<?= $alert["redirect"] ?>';
    <?php endif; ?>
});
```

## 11. Subida de imágenes

Usado en menú (`MenuController::subirImagen()`):

```php
private function subirImagen($campo = 'imagen_file') {
    $ext     = strtolower(pathinfo($file['name'], PATHINFO_EXTENSION));
    $allowed = ['jpg','jpeg','png','webp'];

    if (!in_array($ext, $allowed)) return null;   // extensión no permitida
    if ($file['size'] > 2 * 1024 * 1024) return null; // máx 2MB

    $nombre = 'menu_' . time() . '_' . mt_rand(100,999) . '.' . $ext;
    move_uploaded_file($file['tmp_name'], __DIR__ . '/../img/menu/' . $nombre);
    return $nombre;
}
```

Preview antes de subir (JS con `FileReader`):
```js
const reader = new FileReader();
reader.onload = e => { img.src = e.target.result; }; // muestra localmente
reader.readAsDataURL(file); // sin subir al servidor
```
