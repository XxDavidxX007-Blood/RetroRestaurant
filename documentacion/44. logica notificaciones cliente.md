# 🔔 Notificaciones del Cliente

## ¿Qué es?

Página donde el cliente ve todas sus notificaciones: confirmaciones de pago, actualizaciones de pedidos y promociones próximas a vencer. Al abrirla, todas las notificaciones se marcan como leídas automáticamente.

---

## Archivo

```
views/dashboard/cliente_notificaciones.php
```

---

## Acceso

Solo rol 3 (cliente). Cualquier otro → redirige a `login.php`.

---

## Lo que hace al cargar

Usa `CompraController` (no tiene controlador propio):

```php
require_once __DIR__ . '/../../Controllers/CompraController.php';

// 1. Marca todas las notificaciones del usuario como leídas
CompraController::marcarLeidas($usuario['id_usuario']);

// 2. Trae las últimas 50 notificaciones
$notifs = CompraController::getNotificaciones($usuario['id_usuario'], 50);
```

### `marcarLeidas()`
```sql
UPDATE notificacion SET leida = 1 WHERE id_usuario_destino = :id
```

### `getNotificaciones()`
```sql
SELECT * FROM notificacion
WHERE id_usuario_destino = :id
ORDER BY created_at DESC
LIMIT 50
```

---

## Los 4 tipos de notificación

La función `notifEstilo($tipo)` asigna ícono, color de fondo y etiqueta según el tipo:

| Tipo | Ícono | Color | Etiqueta | Cuándo se crea |
|---|---|---|---|---|
| `pago` | 🎉 | Verde | Pago confirmado | Al confirmar un pedido desde el catálogo |
| `pedido` | 🛍️ | Azul | Pedido | Al crear un pedido (para el admin) |
| `promocion` | 🔥 | Amarillo | Promoción | Automático si hay promos que vencen en 3 días |
| `combo` | 🍱 | Morado | Combo | Reservado para uso futuro |

---

## Cómo se crean las notificaciones

Las notificaciones **no se crean desde esta vista** — se generan en `CompraController::procesarCompra()` al hacer un pedido:

```php
// Al cliente → tipo 'pago':
INSERT INTO notificacion (id_usuario_destino, tipo, titulo, mensaje, id_referencia)
VALUES (:uid, 'pago', '¡Pago confirmado! 🎉', 'Tu pedido #00042 por $25.000...', :id_pedido)

// A todos los admins → tipo 'pedido':
INSERT INTO notificacion (...) VALUES (:uid_admin, 'pedido', 'Nuevo pedido #00042', '...', :id_pedido)
```

Las de tipo `promocion` las genera `CompraController::notificarPromocionesCliente()` — se llama al cargar el dashboard del cliente y crea una notificación por cada promo que vence en los próximos 3 días y aún no fue notificada.

## La vista de cada notificación

Cada notificación muestra:
- **Ícono** con fondo de color según el tipo
- **Badge** de tipo (solo si no está leída)
- **Título** y **mensaje**
- **Tiempo relativo** — calculado con `tiempoRelativo()`:

```php
function tiempoRelativo($fecha) {
    $diff = time() - strtotime($fecha);
    if ($diff < 60)    return 'Hace X seg';
    if ($diff < 3600)  return 'Hace X min';
    if ($diff < 86400) return 'Hace X h';
    return 'Hace X días';
}
```

- **Link de acción** según el tipo:
  - `pago` → "Ver pedido" → `cliente_pedidos.php`
  - `promocion` → "Ver menú" → `cliente_catalogo.php`
  - Otros tipos → sin link

Las notificaciones ya leídas se muestran con `opacity-60` (más tenues).

Si no hay notificaciones → mensaje con link al catálogo:
```html
Sin notificaciones
Aquí verás confirmaciones de pago y promociones especiales.
[Ver menú]
```

## Tabla de la BD

```
notificacion
  ├── id_notificacion
  ├── id_usuario_destino  → usuario (a quién va)
  ├── tipo                → 'pago', 'pedido', 'promocion', 'combo'
  ├── titulo              → texto del encabezado
  ├── mensaje             → texto del cuerpo
  ├── id_referencia       → id del pedido o promoción relacionado
  ├── leida               → 0 = no leída, 1 = leída
  └── created_at          → timestamp de creación
```

## Flujo completo

```
Cliente abre cliente_notificaciones.php
        │
        ├── marcarLeidas() → UPDATE leida=1 para todas sus notifs
        ├── getNotificaciones() → SELECT últimas 50
        └── Renderiza lista
                │
                ├── Notif tipo 'pago'     → 🎉 verde + link "Ver pedido"
                ├── Notif tipo 'pedido'   → 🛍️ azul (sin link)
                ├── Notif tipo 'promocion'→ 🔥 amarillo + link "Ver menú"
                └── Leídas → opacity-60 (más tenues)
```

## Cosas a tener en cuenta

- **Se marcan como leídas al abrir la página** — no hay botón "marcar como leída". En cuanto el cliente entra, todas quedan leídas.
- **El contador del header** (campana con número rojo) se actualiza en el sidebar — usa `CompraController::getNoLeidas()` que cuenta las no leídas. Al abrir esta página ese contador baja a 0.
- **Máximo 50 notificaciones** — las más antiguas no aparecen. No hay paginación.
- **Las notificaciones de tipo `pedido`** son para el admin, no para el cliente — pero si por alguna razón se crean con `id_usuario_destino` del cliente, también aparecerían aquí.
- **`id_referencia`** guarda el `id_pedido` o `id_promocion` relacionado, pero la vista solo lo usa para el link de tipo `pago`. No navega directamente al pedido específico.
