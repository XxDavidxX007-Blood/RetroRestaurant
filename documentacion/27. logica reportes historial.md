# 🗂️ Historial de Reportes Guardados — Reportes

## ¿Qué hace?

Permite guardar un reporte generado para consultarlo después. Muestra una tabla con todos los reportes guardados y permite eliminarlos.

---

## Archivos involucrados

```
views/dashboard/admin_reportes.php    →  tabla del historial + formulario oculto de eliminar
Controllers/ReportesController.php    →  maneja POST de guardar y eliminar
models/Reportes.php                   →  INSERT, SELECT y DELETE en reportes_guardados
```

---

## La tabla `reportes_guardados`

Esta tabla **se crea automáticamente** si no existe, cada vez que se intenta leer o escribir el historial:

```php
// En Reportes::guardarHistorial() y Reportes::obtenerHistorial():
$this->conn->exec("CREATE TABLE IF NOT EXISTS reportes_guardados (
    id_reporte          INT PRIMARY KEY AUTO_INCREMENT,
    fecha_generacion    TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    generado_por_nombre VARCHAR(150) NOT NULL,
    tipo_filtro         VARCHAR(50)  NOT NULL,
    valor_filtro        VARCHAR(100) NOT NULL,
    total_productos     INT          NOT NULL DEFAULT 0,
    valor_total         DECIMAL(12,2) NOT NULL DEFAULT 0,
    datos_json          LONGTEXT
)");
```

No está en el SQL inicial del proyecto — se crea on-demand.

## Guardar un reporte

Al hacer clic en "Guardar en Historial" desde el área imprimible, se envía un formulario con campos ocultos:

```html
<form action="admin_reportes.php" method="POST">
    <input type="hidden" name="accion"          value="guardar_reporte">
    <input type="hidden" name="nombre_usuario"  value="Juan Pérez">
    <input type="hidden" name="tipo_filtro"     value="categoria">
    <input type="hidden" name="valor_filtro"    value="Lácteos">
    <input type="hidden" name="total_productos" value="5">
    <input type="hidden" name="valor_total"     value="75000">
    <input type="hidden" name="datos_json"      value='[{"id_producto":1,...}]'>
</form>
```

El controlador lo recibe y llama al modelo:

```php
// ReportesController::manejarPeticion() → accion=guardar_reporte
$datosGuardar = [
    'nombre_usuario'  => $_POST['nombre_usuario'],
    'tipo_filtro'     => $_POST['tipo_filtro'],
    'valor_filtro'    => $_POST['valor_filtro'],
    'total_productos' => $_POST['total_productos'],
    'valor_total'     => $_POST['valor_total'],
    'datos_json'      => $_POST['datos_json']   // JSON completo de los resultados
];
$this->reportesModel->guardarHistorial($datosGuardar);
header("Location: admin_reportes.php?success=guardado");
exit;
```

```sql
-- Reportes::guardarHistorial()
INSERT INTO reportes_guardados
    (generado_por_nombre, tipo_filtro, valor_filtro, total_productos, valor_total, datos_json)
VALUES (:nombre, :tipo, :valor, :total_prod, :valor_total, :json)
```

## Ver el historial

Al cargar la página, el controlador trae todos los reportes guardados ordenados del más reciente al más antiguo:

```sql
-- Reportes::obtenerHistorial()
SELECT id_reporte, fecha_generacion, generado_por_nombre,
       tipo_filtro, valor_filtro, total_productos, valor_total
FROM reportes_guardados
ORDER BY fecha_generacion DESC
```

Nota: no trae `datos_json` en el listado — ese campo puede ser muy pesado y no se necesita para mostrar la tabla.

La tabla muestra: ID, Fecha/Hora, Generado por, Filtro usado (badge azul), Total productos, Valor total, botón eliminar.

## Eliminar un reporte guardado

El botón de basura llama a JS con confirmación:

```js
function eliminarReporteGuardado(id) {
    if (confirm('¿Estás seguro de que deseas eliminar este reporte guardado? Esta acción no se puede deshacer.')) {
        document.getElementById('delete_id_reporte').value = id;
        document.getElementById('formEliminarHistorial').submit();
    }
}
```

Hay un formulario oculto en la página que se reutiliza para todas las eliminaciones:

```html
<form id="formEliminarHistorial" action="admin_reportes.php" method="POST" class="hidden">
    <input type="hidden" name="accion"      value="eliminar_reporte">
    <input type="hidden" name="id_reporte"  id="delete_id_reporte">
</form>
```

El controlador ejecuta:

```php
// accion=eliminar_reporte
$id = $_POST['id_reporte'];
$this->reportesModel->eliminarHistorial($id);
header("Location: admin_reportes.php?success=eliminado");
exit;
```

```sql
-- Reportes::eliminarHistorial()
DELETE FROM reportes_guardados WHERE id_reporte = :id
```

## Flujo completo guardar → ver → eliminar

```
Admin genera reporte en pantalla
        └── Hace clic en "Guardar en Historial"
                └── POST accion=guardar_reporte
                        └── INSERT en reportes_guardados
                                └── redirect ?success=guardado
                                        └── Banner verde "Reporte guardado exitosamente"
                                                └── Aparece en la tabla del historial

Admin hace clic en 🗑️ de un reporte
        └── confirm() → si acepta
                └── formEliminarHistorial.submit()
                        └── POST accion=eliminar_reporte
                                └── DELETE FROM reportes_guardados
                                        └── redirect ?success=eliminado
                                                └── Banner verde "Reporte eliminado exitosamente"
```

## Cosas a tener en cuenta

- **`datos_json` puede ser muy grande** — guarda el JSON completo de todos los productos del reporte. Si el inventario tiene cientos de productos, este campo puede pesar varios KB por reporte.
- **No hay límite de reportes guardados** — el historial puede crecer indefinidamente. No hay paginación ni limpieza automática.
- **No hay forma de "ver" un reporte guardado** — solo se puede eliminar. El `datos_json` se guarda pero no hay vista para mostrarlo. Si se quisiera agregar, habría que crear una vista que lea ese campo y lo renderice.
- **La tabla se crea automáticamente** — si alguien borra la tabla `reportes_guardados` de la BD, se vuelve a crear sola en el próximo acceso.
- **No hay validación de que el reporte sea del mismo admin** — cualquier admin puede eliminar el reporte guardado por otro.
