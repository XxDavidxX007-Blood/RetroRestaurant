# 🔧 Generador de Reportes — Reportes

## ¿Qué hace?

Permite al admin filtrar el inventario por categoría o estado de stock y ver el resultado en pantalla (imprimible) o descargarlo como CSV para Excel.

---

## Archivos involucrados

```
views/dashboard/admin_reportes.php    →  formulario + área imprimible
Controllers/ReportesController.php    →  detecta el POST, llama al modelo o exporta CSV
models/Reportes.php                   →  query filtrada del inventario
```

---

## El formulario

Tiene 4 controles que cambian dinámicamente:

| Control | Opciones |
|---|---|
| Filtrar por | Todo el inventario / Por categoría / Por estado de stock |
| Categoría (aparece si elige "Por categoría") | Select con categorías de la BD |
| Estado (aparece si elige "Por estado") | Sin stock / Stock bajo / En stock normal |
| Formato | Ver en pantalla / Descargar CSV |

### Mostrar/ocultar selects con JS

```js
function toggleFiltros() {
    const tipo = document.getElementById('tipo_filtro').value;

    // Oculta ambos primero
    document.getElementById('div_categoria').classList.add('hidden');
    document.getElementById('div_estado').classList.add('hidden');

    // Muestra el que corresponde
    if (tipo === 'categoria') {
        document.getElementById('div_categoria').classList.remove('hidden');
    } else if (tipo === 'estado') {
        document.getElementById('div_estado').classList.remove('hidden');
    }
    // Si es 'todo' → ninguno visible
}
```

## El flujo al hacer clic en "Generar Reporte"

```
POST a admin_reportes.php con:
    accion       = 'generar_reporte'
    tipo_filtro  = 'todo' | 'categoria' | 'estado'
    filtro_categoria = id de la categoría (si aplica)
    filtro_estado    = 'sin' | 'bajo' | 'stock' (si aplica)
    formato      = 'pantalla' | 'csv'
        │
        ▼
ReportesController::manejarPeticion()
        │
        ├── Determina el valor del filtro:
        │       if tipo === 'categoria' → valor = id_categoria
        │       if tipo === 'estado'    → valor = 'sin'|'bajo'|'stock'
        │       if tipo === 'todo'      → valor = ''
        │
        ├── Llama a Reportes::obtenerInventarioFiltrado($tipo, $valor)
        │
        └── Si formato === 'csv'     → exportarCSV($resultados) → descarga y exit
            Si formato === 'pantalla' → retorna ['datos'=>..., 'filtros'=>...]
                    └── La vista renderiza el área imprimible
```

## La query filtrada

```php
// Reportes::obtenerInventarioFiltrado($tipo, $valor)

$sql = "SELECT p.id_producto, p.nombre, p.precio, p.unidad,
               c.nombre_categoria as categoria,
               i.cantidad_actual as stock, i.cantidad_minima as minimo
        FROM producto p
        LEFT JOIN categoria_producto c ON p.id_categoria = c.id_categoria
        LEFT JOIN inventario i ON p.id_producto = i.id_producto
        WHERE 1=1 ";

// Filtro por categoría:
if ($tipo === 'categoria' && $valor !== 'todas') {
    $sql .= " AND p.id_categoria = :id_categoria ";
}

// Filtro por estado de stock:
if ($tipo === 'estado') {
    if ($valor === 'sin')   $sql .= " AND i.cantidad_actual = 0 ";
    if ($valor === 'bajo')  $sql .= " AND i.cantidad_actual > 0 AND i.cantidad_actual <= i.cantidad_minima ";
    if ($valor === 'stock') $sql .= " AND i.cantidad_actual > i.cantidad_minima ";
}

$sql .= " ORDER BY p.nombre ASC";
```

El `WHERE 1=1` es un truco para poder agregar condiciones con `AND` sin preocuparse por si es la primera o no.

## El área imprimible (formato pantalla)

Solo aparece si el controlador retornó datos (`$resultadosReporte !== null`). Muestra:

- Encabezado: título, filtro aplicado, fecha y hora, nombre del admin
- Tabla con: ID (ING-001), Producto, Categoría, Stock + unidad, Precio unitario, Valor total, Estado
- Pie de tabla: valor total acumulado de todos los productos del reporte
- 3 botones de acción:

| Botón | Qué hace |
|---|---|
| Imprimir / Guardar como PDF | `window.print()` — usa CSS `@media print` |
| Guardar en Historial | POST con `accion=guardar_reporte` |
| Cerrar Visualización | `display='none'` en el área imprimible |

### CSS de impresión

```css
@media print {
    body * { visibility: hidden; }
    #area-imprimible, #area-imprimible * { visibility: visible; }
    #area-imprimible { position: absolute; left: 0; top: 0; width: 100%; }
    .no-print { display: none !important; }
}
```

Al imprimir, todo el dashboard desaparece y solo queda la tabla del reporte. Los botones tienen clase `no-print` así que tampoco aparecen en el PDF.

### Scroll automático al área imprimible

```js
window.onload = function() {
    if (document.getElementById('area-imprimible')) {
        document.getElementById('area-imprimible').scrollIntoView({ behavior: 'smooth' });
    }
};
```

Cuando la página recarga con el reporte generado, hace scroll automático hasta la tabla.

## Exportar CSV

Si el admin elige "Descargar CSV":

```php
private function exportarCSV($datos) {
    $filename = "reporte_personalizado_" . date('Ymd_His') . ".csv";

    header('Content-Type: text/csv; charset=utf-8');
    header('Content-Disposition: attachment; filename=' . $filename);
    echo "\xEF\xBB\xBF"; // BOM para tildes en Excel

    $output = fopen('php://output', 'w');

    // Encabezados de columnas
    fputcsv($output, ['ID','Producto','Categoria','Unidad','Stock Actual','Stock Minimo','Precio Unitario','Valor Total','Estado']);

    foreach ($datos as $item) {
        $codigo     = 'ING-' . str_pad($item['id_producto'], 3, '0', STR_PAD_LEFT);
        $valorTotal = $item['stock'] * $item['precio'];
        $estado     = 'En stock';
        if ($item['stock'] == 0)                   $estado = 'Sin stock';
        elseif ($item['stock'] <= $item['minimo']) $estado = 'Stock bajo';

        fputcsv($output, [$codigo, $item['nombre'], $item['categoria'], $item['unidad'],
                          $item['stock'], $item['minimo'], $item['precio'], $valorTotal, $estado]);
    }
    fclose($output);
    exit; // Termina la ejecución — no renderiza la vista
}
```

El BOM (`\xEF\xBB\xBF`) es igual que en el exportar de inventario — necesario para que Excel muestre tildes correctamente.

---

## Cosas a tener en cuenta

- **El CSV no usa punto y coma** como separador (a diferencia del exportar de inventario que sí lo usa). Usa la coma por defecto de `fputcsv`. Puede que en Excel en español las columnas no se separen automáticamente.
- **El área imprimible aparece en la misma página** — la página recarga con el reporte visible. Si el admin navega a otra sección y vuelve, el reporte desaparece.
- **Los datos del reporte viajan en campos hidden** al guardar en historial — incluyendo el JSON completo de los resultados en `datos_json`. Esto puede ser pesado si el inventario es grande.
