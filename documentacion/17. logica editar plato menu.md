# ✏️ Editar Plato del Menú — Flujo Completo

## ¿Qué hace?

Permite modificar cualquier dato de un plato ya existente: nombre, categoría, precio, descripción, imagen y si está visible para el cliente o no. Todo desde un modal sin salir de la página.

---

## Archivos involucrados

```
admin_gestion_de_menu.php   →  tabla con el botón ⋮, modal de edición, JS
MenuController.php          →  recibe el POST, sube imagen si hay, llama al modelo
Menu.php                    →  ejecuta el UPDATE en la BD
img/menu/                   →  carpeta donde se guardan las imágenes subidas
```

---

## Paso a paso — lo que ve el admin

```
1. Admin ve la tabla de platos
2. Hace clic en ⋮ (tres puntos) de la fila que quiere editar
3. Se abre un dropdown con "Editar Plato" y "Eliminar del Menú"
4. Hace clic en "Editar Plato"
5. Se abre el modal con todos los datos del plato ya cargados
6. Modifica lo que necesita (imagen es opcional)
7. Hace clic en "Guardar Cambios"
8. La página se recarga con un banner verde de éxito
```

## Paso 1 — El botón ⋮ y el dropdown

Cada fila de la tabla tiene un botón que abre un menú flotante:

```php
// PHP genera un botón y un dropdown por cada plato:
<button onclick="toggleDropdown(<?= $item['id_producto'] ?>)">
    <i class="fas fa-ellipsis-v"></i>
</button>

<div id="dropdown-<?= $item['id_producto'] ?>" class="hidden absolute right-0 ...">
    <a onclick="abrirModalEditar(<?= htmlspecialchars(json_encode($item)) ?>); return false;">
        <i class="fas fa-edit text-blue-500"></i> Editar Plato
    </a>
    <a onclick="abrirModalEliminar(<?= $item['id_producto'] ?>); return false;">
        <i class="fas fa-trash text-red-500"></i> Eliminar del Menú
    </a>
</div>
```

PHP serializa todos los datos del plato como JSON directamente en el HTML. Cuando el admin hace clic, ese JSON ya está disponible en el navegador — no hay petición al servidor para obtener los datos.

```js
function toggleDropdown(id) {
    // Cierra cualquier otro dropdown abierto
    document.querySelectorAll('[id^="dropdown-"]').forEach(el => {
        if (el.id !== 'dropdown-' + id) el.classList.add('hidden');
    });
    // Abre o cierra el de esta fila
    document.getElementById('dropdown-' + id).classList.toggle('hidden');
}

// Si el admin hace clic fuera → cierra todos
window.onclick = function(e) {
    if (!e.target.closest('.dropdown-container')) {
        document.querySelectorAll('[id^="dropdown-"]').forEach(el => el.classList.add('hidden'));
    }
}
```

## Paso 2 — Pre-llenado del modal

Al hacer clic en "Editar Plato", JS recibe el objeto completo del plato y llena cada campo:

```js
function abrirModalEditar(item) {
    // Campos de texto simples
    document.getElementById('edit_id_producto').value  = item.id_producto; // campo oculto
    document.getElementById('edit_nombre').value       = item.nombre;
    document.getElementById('edit_precio').value       = item.precio;
    document.getElementById('edit_descripcion').value  = item.descripcion || '';

    // Checkbox disponible: marcado si disponible == 1
    document.getElementById('edit_disponible').checked = item.disponible == 1;

    // Categoría: busca primero por ID, si no por nombre
    let catSelect = document.getElementById('edit_categoria');
    for (let i = 0; i < catSelect.options.length; i++) {
        if (catSelect.options[i].value == item.id_categoria ||
            catSelect.options[i].text  === item.categoria) {
            catSelect.selectedIndex = i;
            break;
        }
    }

    // Imagen: si es un archivo (tiene punto o barra) → muestra la foto
    //         si es un emoji o está vacía → muestra el emoji
    const previewImg = document.getElementById('edit_preview_img');
    const img = item.imagen || '';
    if (img && (img.includes('/') || img.includes('.'))) {
        previewImg.src = '../../img/menu/' + img;
        previewImg.onerror = function() {
            this.parentElement.innerHTML = '<span class="text-3xl">🍽️</span>';
        };
    } else {
        previewImg.parentElement.innerHTML =
            '<span class="text-3xl">' + (img || '🍽️') + '</span>';
    }

    openModal('modalEditarProducto'); // quita la clase 'hidden' del modal
}
```

## Paso 3 — El modal de edición

Tiene los mismos campos que el formulario de crear, pero pre-llenados:

| Campo | ID del input | Tipo |
|---|---|---|
| ID (oculto) | `edit_id_producto` | `hidden` |
| Nombre | `edit_nombre` | `text` |
| Categoría | `edit_categoria` | `select` |
| Precio | `edit_precio` | `number` |
| Descripción | `edit_descripcion` | `textarea` |
| Imagen | `imagen_file` | `file` (opcional) |
| Disponible | `edit_disponible` | `checkbox` |

El formulario apunta a sí mismo con `method="POST"` y `enctype="multipart/form-data"` (necesario para subir archivos):

```html
<form action="admin_gestion_de_menu.php" method="POST" enctype="multipart/form-data">
    <input type="hidden" name="accion" value="editar">
    <input type="hidden" name="id_producto" id="edit_id_producto">
    ...
</form>
```

### Preview de imagen nueva (antes de guardar)

Si el admin selecciona una imagen nueva, JS la muestra al instante sin subir nada aún:

```js
function previewImagen(input, imgId, iconId, labelId) {
    const file = input.files[0];

    // Validación de peso en el cliente
    if (file.size > 2 * 1024 * 1024) {
        alert('La imagen no puede superar 2MB');
        input.value = '';
        return;
    }

    const reader = new FileReader();
    reader.onload = function(e) {
        document.getElementById(imgId).src = e.target.result; // muestra la imagen
        document.getElementById(imgId).classList.remove('hidden');
        if (labelId) document.getElementById(labelId).textContent = file.name;
    };
    reader.readAsDataURL(file); // lee el archivo localmente, sin subir al servidor
}
```

## Paso 4 — El controlador recibe el POST

```php
// MenuController.php → editar()
private function editar() {
    $id_producto = $_POST['id_producto'];

    // Intenta subir imagen nueva → null si no se subió nada
    $imgNombre = $this->subirImagen();

    $datos = [
        'id_categoria' => $_POST['id_categoria'],
        'nombre'       => $_POST['nombre'],
        'precio'       => $_POST['precio'],
        'descripcion'  => $_POST['descripcion'] ?? '',
        'imagen'       => $imgNombre,          // null = mantener la actual
        'disponible'   => isset($_POST['disponible']) ? 1 : 0
    ];

    $resultado = $this->menuModel->actualizar($id_producto, $datos);

    if ($resultado === true) {
        header("Location: ...admin_gestion_de_menu.php?success=editado");
    } else {
        header("Location: ...admin_gestion_de_menu.php?error=editar");
    }
    exit;
}
```

### La subida de imagen

```php
private function subirImagen($campo = 'imagen_file') {
    if (empty($_FILES[$campo]['name'])) return null; // no subió nada

    $ext     = strtolower(pathinfo($file['name'], PATHINFO_EXTENSION));
    $allowed = ['jpg','jpeg','png','webp'];

    if (!in_array($ext, $allowed)) return null;      // extensión no permitida
    if ($file['size'] > 2 * 1024 * 1024) return null; // más de 2MB

    // Nombre único para evitar colisiones
    $nombre = 'menu_' . time() . '_' . mt_rand(100,999) . '.' . $ext;
    // Ejemplo: menu_1748000000_427.jpg

    move_uploaded_file($file['tmp_name'], __DIR__ . '/../img/menu/' . $nombre);
    return $nombre;
}
```

## Paso 5 — El modelo ejecuta el UPDATE

El modelo tiene dos versiones del UPDATE según si se cambió la imagen o no:

```php
// Menu.php → actualizar()

// Sin imagen nueva → imagen NO aparece en el SET
if ($datos['imagen'] === null) {
    $sql = "UPDATE producto
            SET id_categoria = :id_categoria,
                nombre       = :nombre,
                precio       = :precio,
                descripcion  = :descripcion,
                disponible   = :disponible
            WHERE id_producto = :id_producto AND es_menu = 1";
}

// Con imagen nueva → imagen SÍ se actualiza
else {
    $sql = "UPDATE producto
            SET id_categoria = :id_categoria,
                nombre       = :nombre,
                precio       = :precio,
                descripcion  = :descripcion,
                imagen       = :imagen,
                disponible   = :disponible
            WHERE id_producto = :id_producto AND es_menu = 1";
}
```

El `AND es_menu = 1` es una protección — garantiza que nunca se edite accidentalmente un insumo de inventario aunque alguien manipule el `id_producto` del formulario.

## Flujo completo resumido

```
Admin clic ⋮
    └── toggleDropdown(id) → muestra el menú flotante
            └── clic "Editar Plato"
                    └── abrirModalEditar(item) → llena el modal con los datos del plato
                            └── Admin modifica campos (imagen opcional)
                                    └── POST accion=editar → MenuController::editar()
                                            ├── subirImagen() → guarda en img/menu/ (si hay)
                                            └── menuModel->actualizar(id, datos)
                                                    └── UPDATE producto WHERE es_menu=1
                                                            └── redirect ?success=editado
                                                                    └── banner verde en la vista
```

---

## Cosas a tener en cuenta

- **La imagen anterior no se borra** del servidor si se sube una nueva — queda huérfana en `img/menu/`. No hay limpieza automática.
- **El checkbox `disponible`** no llega en el POST si está desmarcado (comportamiento normal de HTML). El controlador lo maneja con `isset($_POST['disponible']) ? 1 : 0`.
- **No hay validación server-side** de campos obligatorios en el controlador — solo la del HTML (`required`).
- **La categoría se busca por ID primero** en el select, y si no coincide, por nombre. Esto es más robusto que solo buscar por nombre.
- **El modal no hace fetch** — los datos ya viajan en el HTML como JSON. Si el admin tiene la página abierta mucho tiempo y otro admin edita el mismo plato, el modal mostraría datos desactualizados.
