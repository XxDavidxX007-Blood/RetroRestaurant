# 📅 Gestión de Reservas — Vista General

## ¿Qué es?

El módulo de reservas permite al admin crear, editar y eliminar reservas de mesas, y al cliente hacer sus propias reservas y gestionarlas. Ambos tienen su propio panel con KPIs, filtros y tabla paginada.

---

## Archivos que participan

```
views/dashboard/admin_reservas.php    →  panel admin: KPIs, tabla, filtros, 3 modales (crear/editar/eliminar)
views/dashboard/cliente_reservas.php  →  panel cliente: KPIs, tabla, filtros, 2 modales (crear/editar)
Controllers/ReservaController.php     →  lógica admin: CRUD, KPIs, filtros, badges
models/Reserva.php                    →  todas las consultas SQL
```

El panel del cliente no usa `ReservaController` para sus acciones POST — hace las queries directamente en la vista usando el modelo `Reserva` directamente.

---

## Tablas de la BD involucradas

| Tabla | Para qué |
|---|---|
| `reserva` | Registro principal de cada reserva |
| `estado_reserva` | Catálogo de estados (pendiente, confirmada, cancelada, completada, no asistio) |
| `mesa` | Catálogo de mesas con número y capacidad |
| `cliente` | Quién hizo la reserva |
| `usuario` | Nombre y teléfono del cliente |

---

## Los 5 estados de una reserva

| Estado | Color | Quién lo cambia |
|---|---|---|
| pendiente | Amarillo | Estado inicial al crear (cliente o admin) |
| confirmada | Verde | Admin |
| cancelada | Rojo | Admin o cliente |
| completada | Morado | Admin |
| no asistio | Gris | Admin |

---

## Diferencias entre el panel admin y el panel cliente

| Característica | Admin | Cliente |
|---|---|---|
| Acceso | Rol 1 (admin) y rol 2 (empleado) | Solo rol 3 (cliente) |
| Ver reservas | Todas las del restaurante | Solo las suyas |
| Crear | Puede asignar cualquier cliente | Se asigna a sí mismo, estado siempre "pendiente" |
| Editar | Puede cambiar estado | No puede cambiar estado (lo maneja el admin) |
| Eliminar | Cualquier reserva | Solo canceladas, completadas o "no asistio" |
| Cancelar | Cambia estado a cancelada | Botón directo (solo en activas) |
| Filtros de tab | Hoy / Mañana / Esta semana / Todas | Por estado (tabs) |
| Filtro de fecha | Sí | Sí |

## Flujo general

```
ADMIN:
admin_reservas.php carga
    ├── manejarPeticion() → procesa POST si hay (crear/editar/eliminar)
    ├── obtenerDatosVista() → KPIs, reservas filtradas, catálogos
    └── Renderiza tabla + 3 modales

CLIENTE:
cliente_reservas.php carga
    ├── Procesa POST directamente en la vista (crear/editar/eliminar/cancelar)
    ├── Queries directas a la BD para KPIs y listado
    └── Renderiza tabla + 2 modales (crear/editar)
```

---

## Acceso

- **Admin/empleado** → `admin_reservas.php` — si no tiene sesión válida → redirige a `login.php`
- **Cliente** → `cliente_reservas.php` — si no tiene sesión válida → redirige a `login.php`
