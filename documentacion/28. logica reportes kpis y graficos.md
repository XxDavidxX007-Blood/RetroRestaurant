# 📈 KPIs y Gráficos — Reportes

## ¿Qué hacen?

Se calculan automáticamente al cargar la página. No requieren ninguna acción del admin — siempre muestran el estado actual del inventario.

---

## Las 3 KPI cards

### Total Productos
```sql
SELECT COUNT(p.id_producto) as total,
       SUM(p.precio * i.cantidad_actual) as valor
FROM producto p
JOIN inventario i ON p.id_producto = i.id_producto
```
Cuenta cuántos productos tienen registro en inventario (el JOIN excluye los que no tienen fila en `inventario`).

### Valor Total Inventario
Viene de la misma query anterior — es `SUM(precio * cantidad_actual)`. El valor real de todo lo que hay en bodega.

### Usuarios Registrados
```sql
SELECT COUNT(id_usuario) as total FROM usuario
```
Todos los usuarios del sistema sin importar el rol.

## Los 2 gráficos (Chart.js)

### Gráfico de Dona — Valor por Categoría

**Query:**
```sql
SELECT c.nombre_categoria,
       SUM(p.precio * i.cantidad_actual) as valor_total
FROM producto p
JOIN inventario i ON p.id_producto = i.id_producto
JOIN categoria_producto c ON p.id_categoria = c.id_categoria
GROUP BY c.id_categoria
ORDER BY valor_total DESC
```

Muestra cuánto vale el inventario de cada categoría. La categoría con más valor aparece primero.

**Preparación para Chart.js en el controlador:**
```php
foreach ($categoriasData as $cat) {
    $nombresCategorias[] = $cat['nombre_categoria']; // labels
    $valoresCategorias[] = (float)$cat['valor_total']; // data
}
```

**Configuración del chart:**
```js
new Chart(ctxCategorias, {
    type: 'doughnut',
    data: {
        labels: datosCategorias.labels,   // ['Lácteos', 'Carnes', ...]
        datasets: [{
            data: datosCategorias.data,   // [150000, 80000, ...]
            backgroundColor: ['#ef4444', '#3b82f6', '#10b981', ...]
        }]
    },
    options: {
        responsive: true,
        maintainAspectRatio: false,
        plugins: { legend: { position: 'right' } }
    }
});
```

### Gráfico de Pie — Estado General del Stock

**Query + lógica PHP:**
```php
// Trae todos los registros de inventario
SELECT i.cantidad_actual, i.cantidad_minima FROM inventario i

// PHP clasifica cada uno:
foreach ($items as $item) {
    if ($item['cantidad_actual'] == 0)
        $estados['Sin Stock']++;
    elseif ($item['cantidad_actual'] <= $item['cantidad_minima'])
        $estados['Stock Bajo']++;
    else
        $estados['En Stock']++;
}
// Resultado: ['En Stock' => 12, 'Stock Bajo' => 3, 'Sin Stock' => 1]
```

La clasificación ocurre en PHP, no en SQL — se traen todos los registros y se cuentan en un loop.

**Configuración del chart:**
```js
new Chart(ctxStock, {
    type: 'pie',
    data: {
        labels: datosStock.labels,   // ['En Stock', 'Stock Bajo', 'Sin Stock']
        datasets: [{
            data: datosStock.data,   // [12, 3, 1]
            backgroundColor: ['#10b981', '#f59e0b', '#ef4444']
            // verde, amarillo, rojo — mismo código de colores que la tabla de inventario
        }]
    },
    options: {
        responsive: true,
        maintainAspectRatio: false,
        plugins: { legend: { position: 'bottom' } }
    }
});
```

## Cómo viajan los datos de PHP a Chart.js

PHP inyecta los datos directamente en el JS como JSON:

```php
// En el controlador, los datos se preparan como arrays:
return [
    'grafico_categorias' => [
        'labels' => ['Lácteos', 'Carnes', 'Frutas'],
        'data'   => [150000.0, 80000.0, 45000.0]
    ],
    'grafico_stock' => [
        'labels' => ['En Stock', 'Stock Bajo', 'Sin Stock'],
        'data'   => [12, 3, 1]
    ]
];
```

```js
// En la vista, PHP los escribe directamente en el script:
const datosCategorias = <?= json_encode($datosReporte['grafico_categorias']) ?>;
const datosStock      = <?= json_encode($datosReporte['grafico_stock']) ?>;
```

El resultado en el HTML renderizado es algo como:
```js
const datosCategorias = {"labels":["Lácteos","Carnes"],"data":[150000,80000]};
```

## Cosas a tener en cuenta

- **Los datos son en tiempo real** — cada vez que se carga la página se recalculan desde la BD.
- **El gráfico de stock clasifica en PHP**, no en SQL — si el inventario tiene miles de registros, esto podría ser lento. Por ahora es suficiente para el volumen del restaurante.
- **Los colores del pie son fijos** — verde para "En Stock", amarillo para "Stock Bajo", rojo para "Sin Stock". Coinciden con los badges de la tabla de inventario.
- **Si no hay datos** — Chart.js renderiza un gráfico vacío sin errores.
