# 🛵 Domicilios — Vista General del Módulo

## ¿Qué es?

El módulo de domicilios es una **vista filtrada de pedidos** — no tiene su propia tabla en la BD. Muestra únicamente los pedidos cuyo tipo contiene "domicilio" o "delivery". El admin gestiona el estado y puede crear o eliminar domicilios. El cliente ve solo sus propios pedidos a domicilio en modo lectura.

---

## Archivos que participan

```
views/dashboard/admin_domicilios.php    →  panel admin: KPIs, tabla, filtros, 3 modales
views/dashboard/cliente_domicilios.php  →  panel cliente: lista de sus domicilios (solo lectura)
Controllers/DomicilioController.php     →  lógica admin: KPIs, filtros, CRUD, badges
models/Domicilio.php                    →  consultas SQL (todas sobre la tabla pedido)
```

---

## Clave del módulo — no hay tabla propia

Los domicilios **son pedidos normales** de la tabla `pedido`. Lo que los distingue es el `tipo_pedido`:

```sql
-- Filtro base en TODAS las queries del modelo:
WHERE (tp.nombre_tipo LIKE '%domicilio%' OR tp.nombre_tipo LIKE '%delivery%')
```

Esto significa que si un pedido se crea con tipo "domicilio" desde el catálogo del cliente, también aparece aquí.

---

## Tablas de la BD involucradas

| Tabla | Para qué |
|---|---|
| `pedido` | Registro principal (compartido con el módulo de pedidos) |
| `tipo_pedido` | Filtra por nombre que contenga "domicilio" o "delivery" |
| `estado_pedido` | Estados del pedido (pendiente, en_preparacion, listo, entregado, cancelado) |
| `cliente` / `usuario` | Nombre y teléfono del cliente |
| `factura` | Total del pedido |
| `detalle_pedido` | Productos (solo para eliminar y para el conteo en la vista cliente) |
| `mesero` | Empleado asignado al domicilio |

---

## Diferencias entre el panel admin y el panel cliente

| Característica | Admin | Cliente |
|---|---|---|
| Acceso | Rol 1 (admin) y rol 2 (empleado) | Solo rol 3 (cliente) |
| Ver domicilios | Todos los del restaurante | Solo los suyos |
| Crear | Sí — asigna cliente, mesero, fecha y estado | No — los crea desde el catálogo |
| Cambiar estado | Sí — modal dedicado | No |
| Eliminar | Sí — borra pedido + detalle + factura | No |
| Filtros | Tabs por estado + fecha | Tabs por estado (sin fecha) |
| Paginación | Sí (10 por página) | No (lista completa) |

---

## Relación con el módulo de pedidos

Los domicilios y los pedidos comparten la misma tabla `pedido`. La diferencia es solo el filtro de tipo:

```
Módulo Pedidos  → muestra TODOS los pedidos (mesa, domicilio, para llevar)
Módulo Domicilios → muestra SOLO los de tipo domicilio/delivery
```

Un pedido creado desde el catálogo del cliente con tipo "domicilio" aparece en **ambos** módulos.
