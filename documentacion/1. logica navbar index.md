# 🧭 Navbar del `index.php` — Los 4 botones de navegación

## ¿Qué es el navbar?
Es la barra que siempre está visible arriba de la página. Tiene el logo a la izquierda y 4 opciones a la derecha. Dependiendo del botón que toques, o te mueves dentro de la misma página o te llevan a otra.

---

## Comportamiento general

```
Usuario ve el navbar (sticky, siempre arriba)
        │
        ├── Clic en Inicio / Menú / Experiencia
        │       └── Scroll suave a la sección correspondiente (misma página)
        │
        └── Clic en Reservaciones
                └── Fade-out animado → redirige a login.php
```

---

## Los 4 botones uno por uno

### 1. INICIO
```html
<a href="#inicio">Inicio</a>
```
- Es un **ancla interna** — apunta a `<section id="inicio">`, el Hero.
- Al hacer clic, la página hace scroll suave hasta arriba.
- El scroll suave viene de `html { scroll-behavior: smooth; }` en el CSS.
- **No sale de la página.**

---

### 2. MENÚ
```html
<a href="#menu">Menú</a>
```
- Otra **ancla interna** — apunta a `<section id="menu">`, los Platos Signature.
- Mismo comportamiento: scroll suave hacia esa sección.
- **No sale de la página.**

---

### 3. EXPERIENCIA
```html
<a href="#nosotros">Experiencia</a>
```
- Ancla interna que apunta a `<section id="nosotros">`, la sección "Nuestra Filosofía".
- Mismo comportamiento: scroll suave.
- **No sale de la página.**

---

### 4. RESERVACIONES ⭐
```html
<a href="../views/usuarios/login.php" class="btn-gold-outline px-8 py-3 ...">
    Reservaciones
</a>
```
- Este es diferente: **sí sale de la página** y va a `login.php`.
- Tiene estilos propios que lo hacen ver como botón con borde dorado.
- El JS lo intercepta antes de navegar para hacer el efecto de salida.

---

## ¿Por qué Reservaciones se ve diferente?

Tiene la clase `btn-gold-outline`, definida en el CSS del mismo archivo:

```css
.btn-gold-outline {
    border: 1px solid #c5a059;   /* borde dorado */
    color: #c5a059;               /* texto dorado */
    transition: all 0.3s ease;
}

.btn-gold-outline:hover {
    background-color: #c5a059;   /* fondo dorado al pasar el mouse */
    color: #ffffff;               /* texto blanco al pasar el mouse */
}
```

Los otros 3 solo cambian de color al hacer hover:
```css
/* clase de Tailwind aplicada a Inicio, Menú, Experiencia */
hover:text-retro-gold   /* texto se vuelve dorado al pasar el mouse */
```

## El JS que maneja la transición de salida

Solo aplica a **Reservaciones** (el único link que sale de la página):

```js
document.querySelectorAll('a[href]').forEach(link => {
    const href = link.getAttribute('href');

    // Si NO empieza con # → es un link externo, aplicar fade-out
    if (href && !href.startsWith('#') && !href.startsWith('javascript')) {
        link.addEventListener('click', e => {
            e.preventDefault();                        // cancela la navegación inmediata
            document.body.classList.add('fade-out');   // activa animación de salida
            setTimeout(() => {
                window.location.href = href;           // navega después de 400ms
            }, 400);
        });
    }
    // Si empieza con # → scroll suave nativo, el JS no hace nada
});
```

**Resumen:** anclas (`#`) → el navegador las maneja solo con scroll suave. Links reales (`../views/...`) → el JS los intercepta para animar la salida.

## El navbar es sticky — ¿qué significa?

```html
<nav class="sticky top-0 z-50 ...">
```

| Clase | Efecto |
|---    |---     |
| `sticky top-0` | Se pega al tope de la pantalla al hacer scroll |
| `z-50` | Queda por encima de todo el contenido |
| `backdrop-blur-md` | Ligero desenfoque del fondo detrás del nav |
| `bg-retro-light/95` | Fondo blanco con 95% de opacidad (semi-transparente) |

---

## Solo visible en pantallas medianas o más grandes

```html
<div class="hidden md:flex ...">
```

- `hidden` → oculto por defecto (móvil)
- `md:flex` → visible a partir de 768px

En móvil el menú desaparece. No hay hamburguesa implementada aún.
