# 📊 Reportes — Vista General del Módulo

## ¿Qué es?

El módulo de reportes le da al admin una visión del estado del inventario en tiempo real. Tiene gráficos automáticos, un generador de reportes con filtros, exportación a CSV, impresión en PDF y un historial de reportes guardados.

---

## Archivos que participan

```
views/dashboard/admin_reportes.php    →  vista: KPIs, gráficos, generador, historial, área imprimible
Controllers/ReportesController.php    →  coordina: obtiene datos, maneja POST, exporta CSV
models/Reportes.php                   →  todas las consultas SQL
```

También usa `InventarioController` para traer las categorías del select del generador.

---

## Acceso

Solo admin (rol 1). Si no tiene sesión válida → redirige a `login.php`.

---

## Las 4 secciones de la página

```
1. KPIs (3 tarjetas)
        ↓
2. Gráficos (2 charts con Chart.js)
        ↓
3. Generador de Reportes (formulario con filtros)
        ↓
4. Historial de Reportes Guardados (tabla)
```

Si el admin genera un reporte en pantalla, aparece una quinta sección:

```
5. Área Imprimible (tabla detallada + botones de imprimir/guardar/cerrar)
```

---

## Flujo al cargar la página

```
admin_reportes.php carga
        │
        ├── ReportesController::manejarPeticion()
        │       └── Si hay POST → procesa la acción (generar/guardar/eliminar)
        │           Si no hay POST → retorna null
        │
        ├── ReportesController::obtenerDatosGraficos()
        │       ├── obtenerKPIsGenerales()     → 3 números para las tarjetas
        │       ├── obtenerValorPorCategoria() → datos para el gráfico de dona
        │       └── obtenerEstadoStock()       → datos para el gráfico de pie
        │
        ├── InventarioController::obtenerDatosVista()['categorias']
        │       └── Para llenar el select del generador
        │
        └── ReportesController::obtenerHistorial()
                └── Lista de reportes guardados
```

---

## Tablas de la BD involucradas

| Tabla | Para qué |
|---|---|
| `producto` | Nombre, precio, categoría de cada insumo |
| `inventario` | Stock actual y mínimo |
| `categoria_producto` | Nombre de la categoría |
| `usuario` | Conteo total de usuarios registrados |
| `reportes_guardados` | Historial de reportes (se crea automáticamente si no existe) |

---

## Librería externa

**Chart.js** — cargada desde CDN:
```html
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
```

Se usa para los dos gráficos. Los datos los inyecta PHP directamente en el JS como JSON:
```js
const datosCategorias = <?= json_encode($datosReporte['grafico_categorias']) ?>;
const datosStock      = <?= json_encode($datosReporte['grafico_stock']) ?>;
```
