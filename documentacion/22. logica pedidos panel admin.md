# 👨‍💼 Panel de Pedidos — Admin/Empleado

## ¿Qué hace?

Muestra todos los pedidos del restaurante con filtros, KPIs y paginación. El admin puede ver el detalle de cada pedido y cambiar su estado.

---

## Archivos involucrados

```
views/dashboard/admin_pedidos.php         →  vista principal: KPIs, tabla, filtros, modales
views/dashboard/admin_pedidos_detalle.php →  fragmento HTML del detalle (cargado por AJAX)
Controllers/PedidoController.php          →  lógica: filtros, KPIs, cambio de estado
models/Pedido.php                         →  consultas SQL
```

---

## Acceso

Solo admin (rol 1) y empleado (rol 2). Si no tiene sesión válida → redirige a `login.php`.

---

## Las 5 KPI cards

Al cargar la página, el controlador calcula:

```php
// Pedidos de hoy vs ayer (variación porcentual)
$pedidosHoy  = $model->getPedidosHoy();   // COUNT WHERE fecha = CURDATE()
$pedidosAyer = $model->getPedidosAyer();  // COUNT WHERE fecha = CURDATE()-1
$varPedidos  = (($pedidosHoy - $pedidosAyer) / $pedidosAyer) * 100

// Conteo por cada estado de la BD
foreach ($estados as $e) {
    $kpiEstados[$e['nombre_estado']] = $model->getConteoByEstado($e['nombre_estado']);
}
```

| Card | Qué muestra |
|---|---|
| Pedidos hoy | Total del día + % vs ayer |
| En preparación | Pedidos activos en cocina |
| Listos para entregar | Pedidos terminados esperando entrega |
| Completados hoy | Pedidos entregados |
| Cancelados hoy | Pedidos cancelados |

## Filtros

### Tabs de estado
Cada tab es un link que recarga la página con `?estado=nombre_estado`:

```php
<a href="?estado=pendiente">Pendiente</a>
<a href="?estado=en_preparacion">En preparación</a>
// etc.
```

El tab activo se resalta con borde rojo inferior.

### Filtro de fecha
Un `<input type="date">` que al cambiar ejecuta JS:

```js
function aplicarFecha(val) {
    const url = new URL(window.location.href);
    url.searchParams.set('fecha', val);
    url.searchParams.set('pagina', 1); // resetea a página 1
    window.location.href = url.toString();
}
```

Ambos filtros se combinan — puedes ver "pedidos pendientes del 15/05/2026".

## La tabla de pedidos

Columnas: Pedido (#ORD-00001), Cliente, Mesa/Delivery, Estado, Total, Fecha, Acciones.

Cada fila tiene dos botones de acción:

| Botón | Función |
|---|---|
| 👁️ (ojo) | `abrirDetalle(id)` → carga el detalle por AJAX |
| ⋮ (puntos) | `abrirCambiarEstado(id, estadoActual)` → abre el modal de estado |

---

## Modal de detalle (AJAX)

Al hacer clic en el ojo, JS hace un `fetch` a `admin_pedidos_detalle.php?id=X` y pone el HTML resultante dentro del modal:

```js
function abrirDetalle(id) {
    // Muestra spinner mientras carga
    contenido.innerHTML = '<i class="fas fa-spinner fa-spin"></i>';
    modal.classList.remove('hidden');

    fetch('admin_pedidos_detalle.php?id=' + id)
        .then(r => r.text())
        .then(html => { contenido.innerHTML = html; });
}
```

`admin_pedidos_detalle.php` es un fragmento PHP puro — no tiene `<html>` ni layouts. Solo devuelve el HTML del detalle:
- Info del cliente, tipo, mesero, fecha, estado
- Tabla de productos con cantidad y subtotal
- Total en barra oscura al final

## Modal de cambiar estado

```js
function abrirCambiarEstado(id, estadoActual) {
    document.getElementById('estado_id_pedido').value = id;
    document.getElementById('estado_num_pedido').textContent = '#ORD-00001';

    // Pre-selecciona el estado actual en el select
    const sel = document.getElementById('estado_select');
    for (let i = 0; i < sel.options.length; i++) {
        if (sel.options[i].text.toLowerCase().replace(/ /g,'_') === estadoActual) {
            sel.selectedIndex = i; break;
        }
    }
    document.getElementById('modalEstado').classList.remove('hidden');
}
```

El formulario envía POST con `accion=cambiar_estado`, `id_pedido` e `id_estado_pedido`. El controlador ejecuta:

```php
// PedidoController::manejarPeticion()
if ($accion === 'cambiar_estado') {
    $this->model->cambiarEstado($id_pedido, $id_estado_pedido);
    header("Location: admin_pedidos.php?success=estado_actualizado");
    exit;
}
```

```sql
-- Pedido.php::cambiarEstado()
UPDATE pedido SET id_estado_pedido = :estado WHERE id_pedido = :id
```

## Paginación

10 pedidos por página. Los links de paginación preservan los filtros activos con `http_build_query`:

```php
<a href="?<?= http_build_query(array_merge($_GET, ['pagina' => $pagina + 1])) ?>">
    Siguiente
</a>
```

Muestra hasta 5 páginas alrededor de la actual (±2).

## Cosas a tener en cuenta

- **El detalle se carga por AJAX** — si el servidor tarda, el usuario ve un spinner. Si falla, ve un mensaje de error rojo.
- **El cambio de estado no tiene confirmación** — el admin selecciona y guarda directamente. No hay "¿estás seguro?".
- **Los filtros se combinan** — estado + fecha al mismo tiempo.
- **La paginación resetea a página 1** al cambiar la fecha (el JS lo hace explícitamente).
